# 05 — Copy and Trust Rules

## Product voice

Clear, premium, calm and honest. No fake marketplace hype. No overpromising.

## Allowed language

Use:

- `Request a lesson`
- `Contact directly`
- `Protected request`
- `Available to request`
- `Limited availability`
- `Ask LocalSnow for help`
- `LocalSnow helps confirm`
- `Reschedule, replacement or refund/no-charge`
- `Human support`

## Avoid unless literally true

Do not say:

- `Book instantly`
- `Guaranteed instructor`
- `Confirmed availability`
- `Best price`
- `Automatic replacement`
- `Real-time calendar`
- `Free cancellation` unless rules exist
- `No risk` unless legally/product true

## Direct path copy contract

Direct path means:

- client contacts professional/school;
- professional handles response and arrangement;
- LocalSnow provides discovery only;
- no LocalSnow safeguard/guarantee.

Example:

> Your request was sent directly. The professional will handle the response and lesson details. This path is not protected by LocalSnow.

## Protected path copy contract

Protected path means:

- LocalSnow helps make the lesson happen;
- requested professional is tried first;
- if unavailable, LocalSnow helps reschedule, find a suitable replacement, or refund/no-charge depending payment state;
- client approves price increases.

Example:

> LocalSnow will first try to confirm your requested professional. If they cannot take the lesson, we help you reschedule, find a suitable replacement, or refund/no-charge where appropriate. Any higher replacement price is approved by you first.

## Professional setup copy rules

- Explain why each field matters publicly.
- Keep forms human: `Where do you teach?`, not `ProfileResort relation`.
- Avoid admin/platform language before the user has value.
- Draft state is normal.

## SEO copy rules

- Write for the client trying to book, not for Google only.
- Resort pages should include action paths.
- Do not create thin generated pages that make LocalSnow look empty.
